## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/personal-website.git
   cd personal-website
   ```

2. **Open in browser**
   ```bash
   # Simply open index.html in your preferred browser
   open index.html
   ```

3. **Customize content**
   - Edit `index.html` to update personal information
   - Replace photos with your own images
   - Adjust colors and styling in the `<style>` section

## 🎯 Customization Guide

### Personal Information
- Update name, title, and contact details in the hero section
- Modify the about section content
- Adjust experience timeline and projects

### Styling
- Colors are defined in CSS custom properties (`:root`)
- Typography can be changed via Google Fonts imports
- Animation speeds and effects are customizable

### Images
- Replace `ajay-kotnala-photo.jpg` with your primary photo
- Update `ajay-ntt-photo.jpg` with alternative photo
- Adjust image paths in the HTML if needed
